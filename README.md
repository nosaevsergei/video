# TikTok & Shorts Ranking Video Generator

Десктопное приложение на Python (PyQt6 + MoviePy + Pillow + yt-dlp) для автоматизации создания вертикальных (9:16) видео-ранкингов (например, "Top 5 моментов") для TikTok, YouTube Shorts и Reels.

## Возможности
* **Загрузка видео по ссылке**: Прямая интеграция с `yt-dlp`. Вы можете просто вставить ссылку на видео (из TikTok, YouTube и т.д.) вместо выбора локального файла, и приложение автоматически скачает его во временную папку перед рендерингом.
* **Автоматическое кадрирование**: Умное масштабирование и обрезка исходных видео под вертикальный формат `1080x1920` (30 FPS).
* **Кастомизация текста**:
  * Слайдер положения главного заголовка по вертикали (выравнивание по горизонтали центрировано).
  * Слайдеры для смещения списка ранкинга по осям X и Y.
* **Наложение аудио**: Поддержка добавления фонового звука (MP3/WAV) с регулировкой громкости, цикличным повторением и плавным затуханием в конце.
* **Многопоточность**: Процесс рендеринга выполняется в отдельном потоке (`QThread`), благодаря чему интерфейс не зависает.
* **Умное именование файлов**: При сохранении в одну директорию имена автоматически инкрементируются (например, `video.mp4`, `video_1.mp4`), исключая перезапись или ошибки доступа при параллельном рендеринге.

## Как скачать готовое приложение (EXE)

Вы можете скачать уже скомпилированную версию для Windows, не требующую установки Python и зависимостей:
1. Перейдите в раздел **Releases** (Релизы) на странице этого репозитория.
2. Скачайте файл `RankingVideoGenerator.exe`.
3. Запустите файл и пользуйтесь!

## Запуск из исходного кода

Если вы хотите запустить проект локально для разработки:

1. Убедитесь, что у вас установлен Python 3.12+.
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/nosaevsergei/video.git
   cd video
   ```
3. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   # Для Windows (PowerShell):
   .venv\Scripts\Activate.ps1
   # Для Linux/macOS:
   source .venv/bin/activate
   ```
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
5. Запустите приложение:
   ```bash
   python app.py
   ```
